## 📖 О боте

**Fluffy** — специализированный бот для одного Discord-сервера: **Fluffy Town**. Он не является публичным универсальным ботом и не предназначен для установки на другие серверы.

### 🔒 Привязка к Fluffy Town

- В Bothost обязательно указывается числовой ID сервера в переменной окружения `GUILD_ID`.
- Если `GUILD_ID` не задан или равен `0`, бот остановит запуск.
- Slash-команды регистрируются только для указанного сервера, а не глобально.
- Если бота добавят на другой сервер, он автоматически покинет его.
- При повторном подключении бот проверит список серверов и покинет все, кроме Fluffy Town.
- В базе данных сохраняется `guild_id` для дополнительной изоляции данных; это не означает поддержку нескольких серверов.

**Важно:** перед обновлением проверь, что в Bothost в `GUILD_ID` указан именно ID Fluffy Town. Токен бота и другие секреты не публикуй.

### ✨ Ключевые возможности

#### 🛡️ Модерация и безопасность
- **Автомодерация** — фильтрация мата, оскорблений, ссылок, спама, капса, эмодзи и Zalgo-символов.
- **Система предупреждений** — варны с кнопками для администрации (бан, кик, мут, снятие варна).
- **Анти-рейд** — защита от массового создания/удаления каналов и ролей, массовых банов.
- **Бэкапы сервера** — сохранение и восстановление структуры сервера (категории, каналы, роли).

#### 📝 Верификация и управление участниками
- **Анкета с модальным окном** — новые участники заполняют анкету, заявка отправляется модераторам.
- **Кнопки «Принять»/«Отклонить»** — модераторы могут одобрить или отклонить заявку с автоматической выдачей/снятием ролей.
- **Автовыдача ролей** — начальные роли при входе, роль верификации при одобрении.
- **Приветствия и прощания** — кастомные сообщения при входе и выходе.

#### 💬 Взаимодействие и развлечения
- **Фурри-RP команды** — `/фурри вилять`, `/фурри мурчать`, `/фурри обнимать` и многие другие.
- **Игры** — `/игры угадай`, `/игры кнб`, `/игры рандом`, `/игры монетка`.
- **Система идей** — участники могут предлагать идеи, голосовать за них (👍/👎), администрация принимает решение.

#### 🛠️ Инструменты для администраторов
- **Объявления** — красивые embed-объявления с выбором цвета и упоминанием роли.
- **Отправка сообщений** — `/скажи` (текст) и `/скажи_embed` (embed) от имени бота.
- **Навигация** — создание красивых навигационных сообщений с разделами.
- **Ротация статуса** — автоматическая смена статуса бота с никами участников.

#### 🎫 Система тикетов
- Создание тикетов через кнопку.
- Закрытие тикетов с перемещением в архив.
- Логирование создания/закрытия.

## 🚀 Установка и запуск

### Требования
- Python 3.11+
- pip
- Git (опционально)

### Локальная установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Cr1staloriginal/Fluffy.git
cd Fluffy
```
2. Установите зависимости:
```bash
pip install -r requirements.txt
```
3. Скопируйте `.env.example` в `.env` и заполните как минимум `DISCORD_TOKEN` и `GUILD_ID` (ID Fluffy Town).
4. Запустите бота:
```bash
python main.py
```

## ⚙️ Настройки сервера

Настройки сохраняются для единственного разрешённого сервера — Fluffy Town. Доступны:

- `/настройки показать` — показать сохранённые переопределения (право Manage Server).
- `/настройки установить` — сохранить настройку.
- `/настройки сбросить` — удалить переопределение и вернуться к значению по умолчанию.
- `/команда создать` — сохранить пользовательский текстовый ответ без изменения кода.
- `/команда вызвать` — вывести сохранённый ответ.
- `/команда список` и `/команда удалить` — управлять пользовательскими командами.

Пользовательские ответы не могут запускать упоминания @everyone, @here, пользователей или ролей.

## 🎵 Музыка

Команды музыкального плеера:
- `/музыка плей` — найти трек на YouTube или добавить ссылку в очередь.
- `/музыка пауза`, `/музыка возобновить`, `/музыка пропустить`, `/музыка стоп`.
- `/музыка очередь`, `/музыка повтор`, `/музыка сейчас`.

Для работы нужны FFmpeg и PyNaCl. В Docker-образе FFmpeg устанавливается через Dockerfile. На хостинге, который запускает Python напрямую, нужно убедиться, что исполняемый файл `ffmpeg` установлен и доступен в PATH. Музыка использует YouTube через yt-dlp; доступность источников может меняться.

## 🔔 Уведомления YouTube, Twitch и VK

Команды настройки:
- `/интеграции канал` — канал Discord для уведомлений.
- `/интеграции youtube` — добавить YouTube channel ID (начинается с `UC`).
- `/интеграции twitch` — добавить Twitch login.
- `/интеграции vk` — добавить числовой ID сообщества VK.
- `/интеграции список` — показать настройки.
- `/интеграции проверить` — выполнить проверку вручную.

Проверка выполняется раз в 5 минут. Первый запуск запоминает последние публикации/состояние эфира и не отправляет старые уведомления. YouTube работает через RSS без API-ключа. Twitch требует `TWITCH_CLIENT_ID` и `TWITCH_APP_TOKEN`, VK — `VK_ACCESS_TOKEN`. Добавляй секреты только в переменные окружения Bothost; не коммить их в репозиторий и не отправляй в чат.

GitHub Actions запускает компиляцию Python и импорт модулей при push и pull request. Это помогает ловить синтаксические ошибки и ошибки импорта, но не заменяет тестирование в реальном Discord-сервере.

## 🛡️ Настройка анти-рейда

- Удаление **5 каналов за 1 секунду** одним участником/ботом считается рейдом.
- Fluffy ищет виновника в Discord Audit Log с короткими повторами на случай задержки журнала; окно измеряется от момента события, а не от завершения поиска.
- Автоматическое наказание управляется переменной `ANTIRAID_AUTO_PUNISH`: `false` — только уведомление в журнале, `true` — попытка кикнуть найденного участника/бота.
- По умолчанию автоматическое наказание выключено. Не включай `true`, пока не проверены права бота, иерархия ролей и обработка Audit Log в безопасном тестовом сценарии на Fluffy Town.
- Для автоматического режима выдай Fluffy разрешения **View Audit Log** и **Kick Members**. Роль Fluffy должна находиться выше роли нарушителя.
- Если виновник не найден в Audit Log или прав не хватает, бот не угадывает виновника и не применяет наказание к случайному участнику.

### Обновление на Bothost

1. Сначала сохрани копию текущей базы SQLite и текущего `.env`.
2. Проверь, что `GUILD_ID` указывает на Fluffy Town.
3. Обнови код из основной ветки после слияния изменений.
4. Убедись, что включены **Server Members Intent** и **Message Content Intent** в Discord Developer Portal.
5. Перезапусти бота и проверь команды, логи, верификацию и основные сценарии на Fluffy Town.

## 💰 Экономика, репутация и розыгрыши

- `/баланс`, `/ежедневно`, `/перевести`, `/магазин`, `/купить`, `/инвентарь` — серверная валюта и коллекционные предметы.
- `/репутация` показывает репутацию; `/плюс` выдаёт +1 другому участнику не чаще одного раза в 24 часа для каждого пользователя.
- `/розыгрыш_создать` — бесплатный розыгрыш с кнопкой участия и автоматическим завершением. Нужны права Manage Server; денежные ставки и платное участие не предусмотрены.

## 🔊 Временные голосовые комнаты

Чтобы включить комнаты, укажи в переменных Bothost ID голосового лобби в `TEMP_VOICE_LOBBY_ID`. Необязательно задай `TEMP_VOICE_CATEGORY_ID`; если оставить `0`, комнаты будут создаваться в категории лобби. В `TEMP_VOICE_CONTROL_CHANNEL_ID` укажи ID отдельного текстового канала для постоянной панели кнопок; значение `0` отключает панель. `TEMP_VOICE_PREFIX` задаёт префикс имени комнаты. При входе в лобби Fluffy создаёт личную комнату и перемещает туда участника. Владелец управляет ею кнопками: закрывает/открывает, меняет лимит и название, выдаёт/забирает доступ, передаёт владение находящемуся в комнате участнику или удаляет комнату. Если владелец выходит, владение автоматически передаётся одному из оставшихся участников; пустая комната удаляется. Данные владельцев сохраняются в SQLite, а панель восстанавливается после перезапуска. Для работы нужны права Manage Channels и Move Members, а также Connect/View Channel в нужной категории. Боту также нужны View Channel, Send Messages, Embed Links и Read Message History в канале панели.
