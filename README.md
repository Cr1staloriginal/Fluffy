## 📖 О боте

**Пушистик** — это универсальный бот для Discord, созданный с любовью к фурри-сообществу и уютным серверам. Он объединяет в себе мощные инструменты модерации, систему верификации, развлекательные команды и многое другое.

### ✨ Ключевые возможности

#### 🛡️ Модерация и безопасность
- **Автомодерация** — фильтрация мата, оскорблений, ссылок, спама, капса, эмодзи и Zalgo-символов.
- **Система предупреждений** — варны с кнопками для администрации (бан, кик, мут, снятие варна).
- **Анти-рейд** — защита от массового создания/удаления каналов и ролей, массовых банов. По умолчанию работает в режиме журналирования без автоматических наказаний; для включения наказаний после проверки порогов установите `ANTIRAID_AUTO_PUNISH=true`.
- **Бэкапы сервера** — сохранение и восстановление структуры сервера (категории, каналы, роли).

#### 📝 Верификация и управление участниками
- **Анкета с модальным окном** — новые участники заполняют анкету, заявка отправляется модераторам.
- **Кнопки «Принять»/«Отклонить»** — модераторы могут одобрить или отклонить заявку с автоматической выдачей/снятием ролей.
- **Автовыдача ролей** — начальные роли при входе, роль верификации при одобрении.
- **Приветствия и прощания** — кастомные сообщения при входе и выходе участников.

#### 💬 Взаимодействие и развлечения
- **Фурри-RP команды** — `/фурри вилять`, `/фурри мурчать`, `/фурри обнимать` и многие другие.
- **Игры** — `/игры угадай`, `/игры кнб`, `/игры рандом`, `/игры монетка`.
- **Система идей** — участники могут предлагать идеи, голосовать за них (👍/👎), администрация принимает решение.

#### 🛠️ Инструменты для администраторов
- **Объявления** — красивые embed-объявления с выбором цвета и упоминанием роли.
- **Отправка сообщений** — `/скажи` (текст) и `/скажи_embed` (embed) от имени бота.
- **Навигация** — создание красивых навигационных сообщений с разделами.
- **Ротация статуса** — автоматическая смена статуса бота с никами участников.

#### 🎫 Система тикетов
- Создание тикетов через кнопку.
- Закрытие тикетов с перемещением в архив.
- Логирование создания/закрытия.

## ⚙️ Настройки сервера и пользовательские команды

В текущей ветке добавлена основа настроек, разделённых по ID Discord-сервера. После включения изменений в основную ветку и перезапуска бота доступны:

- `/настройки показать` — показать сохранённые переопределения (право Manage Server).
- `/настройки установить` — сохранить настройку для текущего сервера.
- `/настройки сбросить` — удалить переопределение и вернуться к значению по умолчанию.
- `/команда создать` — сохранить пользовательский текстовый ответ без изменения кода.
- `/команда вызвать` — вывести сохранённый ответ.
- `/команда список` и `/команда удалить` — управлять пользовательскими командами.

Пользовательские ответы не могут запускать упоминания @everyone, @here, пользователей или ролей. Настройки, которые уже использовались существующими модулями через переменные окружения, переводятся на серверную конфигурацию поэтапно; наличие настройки в БД само по себе ещё не означает, что каждый модуль уже читает её.

## 🎵 Музыка

Команды музыкального плеера:
- `/музыка плей` — найти трек на YouTube или добавить ссылку в очередь.
- `/музыка пауза`, `/музыка возобновить`, `/музыка пропустить`, `/музыка стоп`.
- `/музыка очередь`, `/музыка повтор`, `/музыка сейчас`.

Для работы нужны FFmpeg и PyNaCl. В Docker-образе FFmpeg устанавливается через Dockerfile. На хостинге, который запускает Python напрямую, нужно убедиться, что исполняемый файл `ffmpeg` установлен и доступен в PATH. Музыка использует YouTube через yt-dlp; доступность источников может меняться.

## 🔔 Уведомления YouTube, Twitch и VK

Команды настройки:
- `/интеграции канал` — канал Discord для уведомлений.
- `/интеграции youtube` — добавить YouTube channel ID (начинается с `UC`).
- `/интеграции twitch` — добавить Twitch login.
- `/интеграции vk` — добавить числовой ID сообщества VK.
- `/интеграции список` — показать настройки.
- `/интеграции проверить` — выполнить проверку вручную.

Проверка выполняется раз в 5 минут. Первый запуск запоминает последние публикации/состояние эфира и не отправляет старые уведомления. YouTube работает через RSS без API-ключа. Twitch требует `TWITCH_CLIENT_ID` и `TWITCH_APP_TOKEN`, VK — `VK_ACCESS_TOKEN`. Добавляй секреты только в переменные окружения Bothost; не коммить их в репозиторий и не отправляй в чат.
