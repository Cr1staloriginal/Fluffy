# Квест Fluffy Town: «Тайна пропавшего хвоста»

## Как устроен модуль

Файл cogs/event_quest.py загружается существующим автозагрузчиком Fluffy. Отдельные таблицы SQLite хранят состояние квеста, список кодовых слов, участников и засчитанные ответы. Данные не смешиваются между Discord-серверами.

Подсказки публикует организатор вручную в каналах сервера. Fluffy не публикует загадки и не раскрывает ответы участникам.

## Подготовка организатором

1. Убедись, что Fluffy обновлён и запущен.
2. В Discord добавь правильные ответы через /event_code_add.
3. Проверь их командой /event_code_list. Ответ виден только тому, кто вызвал команду. Если ошибся до старта, используй /event_code_remove и добавь правильный ответ заново.
4. Перед началом квеста запусти /event_start.
5. После финала 31 октября выполни /event_close.
6. Покажи участникам итоговый рейтинг через /event_rank.

Команды управления требуют право Discord «Управлять сервером».

## Предлагаемые ответы и очки

Введи команды по одной:

- /event_code_add answer:ФОНАРЬ points:10
- /event_code_add answer:ЛУНА points:10
- /event_code_add answer:ИСКРА points:10
- /event_code_add answer:КОМЕТА points:10
- /event_code_add answer:ЗВЕЗДА points:10
- /event_code_add answer:КРИСТАЛЛ points:10
- /event_code_add answer:МЕСТО, ГДЕ КАЖДОМУ ЕСТЬ МЕСТО points:25

Последняя фраза — пример финального ответа. Если финальная загадка будет сформулирована иначе, замени её на выбранный тобой точный ответ до старта.

При проверке бот игнорирует регистр, пробелы и знаки препинания. Например, «Место, где каждому есть место» и «МЕСТО ГДЕ КАЖДОМУ ЕСТЬ МЕСТО» считаются одинаковыми ответами.

## Команды участников

- /event_join — регистрация.
- /event_answer answer:... — отправить кодовое слово.
- /event_rank — топ-10 участников.
- /event_stats — число участников, добавленных ответов и засчитанных решений.
- /event_reset — очистить тестовые результаты и участников, сохранив правильные ответы (только организатору).

За один и тот же ответ одному участнику очки начисляются только один раз. Ошибочные ответы не дают очков.

## Проверка перед открытием

1. Добавь все семь ответов.
2. Выполни /event_start.
3. Зарегистрируй тестового участника командой /event_join.
4. Отправь один правильный ответ через /event_answer.
5. Повтори тот же ответ: бот должен отказать в повторном начислении.
6. Проверь /event_rank и /event_stats.
7. После проверки выполни /event_reset: команда удалит тестовые результаты и участников, но сохранит список кодов. Перед настоящим мероприятием запусти /event_start.

Не публикуй список правильных ответов в общедоступных каналах. Не используй /event_close до завершения финала, иначе участники не смогут отправлять ответы.
